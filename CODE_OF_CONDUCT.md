# Code of Conduct

This is a small, single-maintainer project, so this is short.

## The standard

Be straightforward and be decent. Technical disagreement is welcome — this repository exists
partly to have its reasoning checked. Personal attacks, harassment, discrimination, or
demeaning language are not welcome, and neither is bad-faith noise.

Concretely, that means:

- **Critique the work, not the person.** "This claim isn't supported by its evidence pointer"
  is exactly the kind of issue this project wants. "This is garbage" is not.
- **Assume competence and good faith** in others, and extend the same courtesy you'd want.
- **Respect the security policy.** Undisclosed vulnerabilities go to email, not public issues.
- **No harassment of any kind**, including in private channels reached through this project.

## Scope and enforcement

This applies to issues, pull requests, discussions, and any direct contact arising from this
repository.

Report a problem to **john@agilegypsy.com**. Reports are handled privately. As maintainer,
John may edit, lock, or remove contributions that breach this, and may block accounts that
persist. There is no committee here — the response will be a human judgement call, made in
good faith and explained.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/).
